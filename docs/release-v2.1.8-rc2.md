# Release Note · tdx-api v2.1.8-rc2 — 量比接口

> 状态：**rc2（未合入 main，待下游回归）** · 2026-10-28
> 测试实例：`http://<宿主机>:18080`（docker 镜像 `tdx-stock-web:v2.1.8-rc2`，独立数据卷）

## rc1 → rc2 修复（对下游反馈的两个问题的回应）

1. **老日期查询失败（下游问题 1）**：根因是分母日K只取最近 15 根再往回筛，目标日早于最近约 15 个交易日必然筛空报"无日K数据"。已改为从最近往回翻页（每页 800 根，至多 10 页）直至收集满目标日之前 5 根。**修复后 2025-08-15（约 14.5 个月前）可正常查询，且分子与日K逐手一致**（600000 @ 2025-08-15：tick 重建全天量 930,678 = 日K 930,678）。
2. **收盘累计欠计数（下游问题 2）**：根因不是漏 tick，而是重建时间轴的边界偏移 bug——15:00（收盘集合竞价）/11:30 标签的 tick 被放到全天范围之外静默丢弃。修复后**全天 tick 重建量与日K逐手一致**（±1 手取整）。600519 @ 2026-10-27 收盘量比修正为 **0.9232**（此前 0.8902，差的 1,382 手正是 15:00 bar）。rc1 文档所称"≈0.2% 噪声"即此 bug，已不存在。
> 生产实例（8080）仍为 v2.1.7，验收后统一切换；本版本为**纯增量**变更，不改动任何既有端点，下游无需迁移。

## 1. 新增能力

量比（volume ratio）指标，**通达信线性口径**，与电脑端通达信软件分钟级显示逐点一致（两位小数）：

| 端点 | 场景 | 粒度 |
|---|---|---|
| `GET /api/volume-ratio?codes=` | 实盘快照 | 实时（建议 ≥5s 轮询，≤20 只/次） |
| `GET /api/volume-ratio/history?code=&date=&granularity=5s\|1m` | 历史回测 | 5 秒（2880 点/天）或 1 分钟（240 点/天） |

## 2. 口径契约（重要，跨仓约定）

```
量比(t) = 当日累计成交量(t) ÷ ( 前5个交易日平均每分钟成交量 × 已开市分钟数(t) )
```

- **分母**：目标日之前 5 个交易日的日K总量 ÷ 1200。基准日按**个股实际交易日**滚动（停牌日无日K bar 自动跳过）；上市不足 5 日时用实际天数，`basis_days` 字段标明。
- **集合竞价量（09:25）计入分子**，从 t=0 起生效（与分时图第一根 bar 含竞价量一致）。开盘瞬间量比会因竞价量一次性计入而极高，软件同此行为。
- **已开市分钟数**为交易时钟：早盘 09:30-11:30、午盘 13:00-15:00，午休（11:30-13:00）冻结计时，15:00 后封顶 240 分钟。
- 实时端点在**未开盘或竞价阶段（elapsed=0）时 `ratio=null`**；收盘后返回当日终值。
- ⚠️ 本口径与既有 `/api/realtime/quote` 推送的 `volume_ratio` 字段**不是同一口径**（后者为"同时段累计均值"口径，需 preheat）。两套并存、各有用途，**请勿混用或要求互相"修齐"**。

## 3. 实盘快照：`GET /api/volume-ratio`

**请求**：`codes`（必填，逗号分隔，≤20 只；接受 `600000.SH` / `SH600000` / `600000` 三种格式）

**响应**（标准信封，`data` 结构）：

```json
{
  "ts": 1793178440,
  "elapsed_seconds": 14400,
  "list": [
    {
      "code": "300613.SZ",
      "ts": 1793178440,
      "cum_volume": 149219,          // 当日累计量（手），含集合竞价
      "elapsed_seconds": 14400,      // 已开市秒数，0=未开盘/竞价中
      "avg_per_min": 575.979,        // 分母：前5日平均每分钟量（手/分钟）
      "basis_days": 5,               // 实际基准天数
      "ratio": 1.0795,               // 量比；elapsed=0 或异常时为 null
      "error": ""                    // 单只失败原因，成功时省略
    }
  ]
}
```

**调用建议**：
- 轮询节奏 ≥5 秒/次，单次 ≤20 只（超限整单拒绝 `"codes 最多 20 只"`；若负载吃紧服务端会下调上限，请容错该错误文案）。
- 首次查询某只票会多 1 个日K请求（构建分母），当日内服务端缓存，之后每轮仅 1 个批量行情请求（20 只实测 ≈60ms）。
- **只在交易时段调用**。非交易日/盘前（行情未滚动到当日）会返回 per-item 错误 `"非当日行情 (未开盘或非交易日)"`，`ratio=null`，这不是故障，请按静默处理或降频。
- 批次内的非沪深京代码（如港股）被**按只隔离**：该只返回 `"非沪深京市场, 标准行情不支持"`，不影响批次内其余股票。

## 4. 历史序列：`GET /api/volume-ratio/history`

**请求**：

| 参数 | 说明 |
|---|---|
| `code` | 必填，单只，格式同上；仅沪深京 |
| `date` | 必填，`2026-10-28` 或 `20261028` |
| `granularity` | 可选，`5s`（缺省）/ `1m` |

**响应**：

```json
{
  "code": "300613.SZ",
  "date": "20261028",
  "granularity": "1m",
  "avg_per_min": 575.979,
  "basis_days": 5,
  "basis_dates": ["20261021", "20261022", "20261023", "20261026", "20261027"],
  "count": 240,
  "list": [
    { "time": "09:31:00", "ratio": 56.98, "volume": 32819 },
    { "time": "09:32:00", "ratio": 49.34, "volume": 24016 }
  ]
}
```

**粒度语义**：
- `5s`：09:30:05 起、每 5 秒一点到 15:00:00，全天 2880 点。`time` 为桶右边界；`volume` 为该 5 秒桶成交量（手）。
- `1m`：09:31:00..15:00:00 共 240 个整分钟点，**即 5s 序列的整分钟边界点**（量比是累计口径，分钟值=该分钟结束时刻的值，无需对桶内点做任何平均）。两种粒度同源同路径，数值严格一致。
- **分钟级与通达信软件完全一致**（已逐点核验）；分钟边界累计精确等于分时 bar。
- 5s 序列由分时成交快照（3 秒栅格）重建：开盘爆量时段为满密度快照、时间对齐精确；成交极稀疏的时段存在 ≤3 秒的时间归位不确定度（对量比数值影响可忽略）。

**调用建议**：
- **历史数据请盘后获取**：历史 tick 端点盘中对"当日"返回不完整数据；盘中当日的量比请走实时端点。
- 数据保留：历史分时成交**实测 ≥630 自然日（约 21 个月）**；基准侧日K更深（翻页取数）。超范围/非交易日返回错误 `"该日期无分时成交数据 (非交易日或超出服务器保留范围)"`。
- 回测批量拉取时无需顾虑配额：每次查询 = 1 次日K + 数次分页 tick（全天 tick 通常 <8000 条），纯内存计算，无落库。
- 重建量完整性：**全天 5s 桶加总与日K成交量逐手一致（±1 手取整）**，无系统性欠计数。15:00 后的盘后 tick（大宗/盘后定价，实测数十手量级）不计入——与日K口径一致（已实测 600519 @ 2026-10-27：日K 38,669 = tick 时段内加总，分毫不差）。

## 5. 验证锚点（300613 · 2026-10-28，可用于下游回归）

| 时刻 | 量比 | 时刻 | 量比 |
|---|---|---|---|
| 09:30:05 | 278.01 | 09:33:00 | 48.73 |
| 09:31:00 | **56.98** | 09:34:00 | 44.51 |
| 09:32:00 | 49.34 | 09:35:00 | **38.02** |

- 分钟级各点与电脑端通达信软件**两位小数完全一致**（09:31-09:45 已逐点核对）。
- 300613 @ 2026-10-28 收盘终值 = **1.0795**（tick 口径与实时 quote 口径一致）。
- 600519 @ 2026-10-27 收盘终值 = **0.9232**（= 日K 38,669 手 ÷ (174.52×240)，15:00 收盘集合竞价 1,382 手已含）。
